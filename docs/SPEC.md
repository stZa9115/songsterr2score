# 規格

## 目標

本機 Web 工具：使用者上傳瀏覽器另存的 Songsterr 譜頁 (.html)，確認或修改譜名後轉換，
取得五線譜、TAB、兩者合併三份 PDF。支援四弦 bass 與六弦吉他。

## 使用情境

- 使用者從 GitHub clone 專案，在自己的電腦上執行；單人使用，只聽 `127.0.0.1`。
- 需要自行安裝 uv 與 LilyPond。找不到 LilyPond 時，UI 要明確告知無法產生 PDF 以及如何安裝。

## 技術選擇

- 後端：FastAPI，沿用 `songsterr2score/core.py` 的轉換邏輯。
- 前端：單一靜態 HTML 檔（原生 JS/CSS，不需要 build 步驟），由 FastAPI 提供。
- 啟動：一個指令啟動伺服器並開啟瀏覽器。

## 流程

1. 選擇或拖放一個 .html 檔上傳。
2. 伺服器解析後回傳：頁面標題、預設譜名、弦數、調弦、小節範圍、解析警告。
3. 頁面顯示可編輯的譜名欄位（預填預設譜名）與上述資訊。
4. 使用者按下轉換。
5. 頁面顯示三個 PDF 連結（可在瀏覽器開啟或下載）與轉換警告。

## 譜名

- 預設譜名為「曲名 - 藝人」，由頁面 `<title>` 解析。
  例：`【MV】プロポーズ Bass Tab by 9Lana | Songsterr Tabs with Rhythm` → `【MV】プロポーズ - 9Lana`。
- 標題不符合預期格式時，退回使用 `|` 之前的完整標題。
- 譜名同時作為 PDF 內的標題與輸出檔名。
- 檔名中 Windows 不允許的字元 `\ / : * ? " < > |` 換成 `_`，去除首尾空白與句點；保留 Unicode。
- 譜名為空時不可轉換。

## 輸出

寫入專案的 `output/` 資料夾，同名檔案直接覆寫：

| 檔案 | 內容 |
| --- | --- |
| `{譜名}_staff.pdf` | 只有五線譜 |
| `{譜名}_tab.pdf` | 只有 TAB |
| `{譜名}_both.pdf` | 五線譜 + TAB |
| `{譜名}.musicxml`、`{譜名}_*.ly` | 保留在 `output/`，UI 不顯示 |

## 六線譜

- 六弦吉他譜：調弦由頁面資料讀取，五線譜使用 `treble_8` 譜號。
- 和弦（同一拍多個音）在五線譜與 TAB 都要正確呈現。
- 推弦、滑音、悶音、連結線等技巧記號不在目前範圍內。

## 錯誤處理

- 上傳的檔案不是 Songsterr 譜頁或找不到譜面：回傳清楚的繁中錯誤訊息，伺服器不可中斷。
- 解析警告（缺譜行、無法辨識的符號、拍數不符等）要顯示給使用者，不可只印在終端機。
- 只接受 .html；上傳大小上限 20 MB。

## 不在範圍內

部署到網路、多人同時使用、帳號、歷史紀錄、直接由網址抓取 Songsterr。
